# 데모 MES 데이터 사용 가이드

데모용 가상 문서입니다. 실제 시스템의 사실이 아닙니다.

## 센서 데이터 조회

sensor_reading은 1초 단위로 쌓이며 월별 파티션으로 나뉜다.
sensor_reading을 조회할 때는 반드시 reading_time 기간 조건을 건다. 한 번에 31일을 넘기지 않는다.
기간 조건 없이 조회하면 전체 파티션을 읽어 운영 DB가 멈춘 적이 있다.
장기 추세는 daily_equipment_avg 뷰를 사용한다.

## 사업장별 집계

사업장별 설비 용량은 site → equipment로만 집계한다.
equipment와 sensor_reading을 함께 조인한 뒤 capacity_kw를 합계하면 측정 건수만큼 용량이 중복 합산된다.
측정값과 용량을 같이 보려면 설비 단위로 먼저 집계한 뒤 조인한다.

## 용어

MES에서 "사업자번호"는 두 가지로 쓰인다.
site.biz_no는 공장(사업장) 자체의 사업자등록번호다.
equipment.vendor_biz_no는 설비를 납품한 공급업체의 사업자등록번호다.

## 없는 기능

설비 마스터 변경 이력은 보관하지 않는다. equipment는 수정 시 현재 값을 덮어쓴다.
과거 시점의 설비 용량이 필요하면 변경 요청서(ITSM 티켓)를 확인해야 한다.
